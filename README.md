# 高校考试网 · 学习助手（Gaoxiao Exam Assistant）

> 一个用于对 **高校考试网（gaoxiaokaoshi.com）** 的「登录 → 课程选择 → 视频学习 → 课后作业」流程做自动化 **功能测试** 的工具。
> 同时提供**图形界面（exe）**与**命令行（CLI）**两种用法，零第三方依赖。

⚠️ **定位与合规**：本工具面向教学平台的功能测试（QA）。请**只**用于你有权操作的账号（如测试账号、你本人账号），并遵守平台服务条款。视频时长累计受服务端防刷机制限制（1 倍速真实时间），本工具不做绕过，也请勿滥用。

---

## ✨ 功能特性

- **一键全自动**：登录 → 选择学习计划 → 自动学习所选课程（默认全部）→ 每课学完自动进入课后练习。
- **视频学习·并发**：同一账号可同时学习多门课程（实测 36 门并发，服务端按学习会话独立累计，互不冲突），总耗时约等于最长课时，而非串行累加。
- **课后作业·两遍制**：
  - **第一遍**：客观题全选猜测项（默认 C）交卷，从答卷页解析每题**标准答案**并记录到答案库。
  - **第二遍**：重新开考，按题干在答案库中匹配答案作答（题序变化不影响），交卷后校验是否达到及格分。
- **图形界面（GUI）**：账号/课程一目了然，实时滚动日志，设置页可调并发、视频、作业等参数。
- **命令行（CLI）**：适合构造更多账号/更细粒度参数的批量测试。
- **零第三方依赖**：Node.js 直接用 Chrome DevTools 协议（CDP）驱动本机 Edge/Chrome；GUI 用 Windows 自带 .NET Framework 编译，无需联网安装任何包。



## 🏗 构建 GUI exe

程序已包含脚本 `build.bat`（使用 .NET Framework 自带 C# 编译器 `csc`，无需联网）。等价的手动命令：

```bat
csc /nologo /target:winexe /out:高校考试助手.exe /r:System.Windows.Forms.dll /r:System.Drawing.dll gui\Program.cs
```

### 打包"免安装 Node"的离线版（推荐给普通使用者）

运行 `build_release.bat`（需联网一次，用于下载可移植 Node），它会：
1. 编译 GUI exe；
2. 下载 Node.js 可移植版到 `node\`；
3. 组装成 `高校考试网学习助手-离线版-v1.0.0.zip`。

使用者解压后双击 `高校考试助手.exe` 即可运行，**无需安装 Node**（浏览器用 Win10/11 自带的 Edge）。包内只含运行必需文件（exe、`main.mjs`、`lib\`、`tools\cdp.mjs`、`node\node.exe`、README/LICENSE），不含源码/构建脚本/个人账号。

**在"空白电脑"上运行的要求**：Windows 10/11（.NET Framework 4.x、Edge 均系统自带）+ 可访问目标网站。请把压缩包解压到**可写目录**（如桌面/文档/下载）再双击 exe；浏览器的临时 profile 会写入系统临时目录，不依赖解压位置。

## 📄 配置说明（config.json）

| 字段 | 说明 |
| --- | --- |
| `site.base_url` | 平台地址 |
| `site.browser` | `edge` / `chrome` |
| `site.headless` | `true` 无头运行；`false` 弹出浏览器窗口便于观察 |
| `concurrency.max_accounts` | 同时运行的账号数（各账号独立浏览器/登录态） |
| `concurrency.parallel_lessons` | 同账号内并行学习的课时数（可设为全部课时） |
| `concurrency.cdp_base_port` | 各浏览器 CDP 调试端口起始值（自动递增） |
| `video.mode` | `full`：观看至课时完成；`skip`：跳过观看直接做作业 |
| `video.max_watch_sec` | 单课时观看上限（秒），超时未完成则记录并继续 |
| `video.poll_sec` | 学习进度轮询间隔（秒） |
| `video.stall_tolerance_min` | 进度停滞超过该分钟数则刷新学习会话（**建议大于轮询间隔**） |
| `homework.passes` | 作业遍数（默认 2：第一遍收集、第二遍作答） |
| `homework.first_pass_guess` | 第一遍猜测项（默认 C，选项无 C 时取第一个） |
| `homework.answers_file` | 答案库文件（默认 answers.json） |
| `homework.min_score` | 第二遍及格判定分（默认 60） |
| `accounts[].name` | 账号别名 |
| `accounts[].username` / `password` | 账号密码 |
| `accounts[].plan` | 学习计划名（如「军事理论」），留空用第一个 |
| `accounts[].lessons` | 要学习的课时名（子串匹配），留空 = 该计划全部课时 |
| `accounts[].watch_videos` / `do_homework` | 是否观看视频 / 是否做作业 |

> 公开仓库请使用 `config.example.json`（账号为占位符）；你的 `config.json` 已加入 `.gitignore`，不会被提交。

## ⚙️ 工作流程

1. **登录**：打开 `Login.aspx` → 填账号密码 → 提交 → 进入主面板。
2. **选课**：进入「我的课程」，按 `plan` 切换学习计划，遍历分页收集课时，按 `lessons` 过滤。
3. **视频学习（并发）**：为每个目标课时打开学习页。平台按播放器心跳计时（`updateTime.ashx`，服务端按真实流逝时间校验、1 倍速累计、不可加速）；工具驱动等效 1 秒时钟、每 60 秒上报一次，并定期轮询课时进度，直到「已完成学时 ≥ 学时要求」；进度停滞超过容忍值自动刷新会话。
4. **课后作业（两遍制）**：课时完成后「参加练习」解锁——
   - 第一遍：客观题选猜测项交卷，从 `viewExam.aspx` 解析标准答案与得分写入答案库。
   - 第二遍：重新开考，按题干匹配答案作答，交卷后校验及格。
5. 汇总每个账号课时完成情况与各遍得分，写入日志。

## 🌐 多并发说明

- **多账号并发**：每个账号独立浏览器实例（独立登录态），互不影响。
- **同账号多课时并发**：平台按学习会话独立累计时长，同一账号可同时学习全部课时（实测 36 门并发）。总耗时 ≈ 最长课时时长。
- 视频时长被服务端限制为真实时间 1 倍速，属平台防刷机制；并行只是把多个课时的 1 倍速同时进行，从而压缩总耗时。
- **内存提示**：并发越高，浏览器内存/CPU 占用越多（每课时一个标签页）。若机器卡顿，降低 `parallel_lessons`（如 10~12）。
- **进度轮询**：账号级统一轮询器，每个周期翻页读取一次完整列表并广播给所有并发课时，避免高并发下各自拉列表压垮页面。

## ❓ 常见问题

- **登录后未跳转**：多为账号密码错误，日志会打印页面内容。
- **作业未解锁**：课时未「已完成」时「参加练习」不可用（提示：请先完成学习！），工具会跳过并提示；先完成该课视频学习即可。
- **提示「未提取到题目」**：平台存在两种考试页（`ExamMain.aspx` 与 `ExamTmStepMain.aspx`），工具已兼容两种题目结构。
- **进度不停刷新（刷新学习会话刷屏）**：「停滞容忍」设得过小（小于轮询间隔）。建议设为 **3~8 分钟**，且**大于** `video.poll_sec`。
- **exe 提示找不到 node 或启动失败**：确认已安装 Node 且在 PATH 中，`高校考试助手.exe`、`main.mjs`、`config.json` 同目录。
- **想看着它自动操作**：把 `config.json` 中 `site.headless` 设为 `false`，会弹出可见浏览器窗口。
